# Ark Manager 1.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish Ark Manager 1.1.0 with an exhaustive changelog derived from every user-facing change after v1.0.1.

**Architecture:** README is the durable project-facing changelog. The same approved content is converted to a plain-text GitHub Release body so the Electron updater can display it directly. Existing electron-builder artifacts provide the installer and updater metadata.

**Tech Stack:** Markdown, Git, GitHub CLI, electron-builder, electron-updater

## Global Constraints

- Release version is exactly `1.1.0` and tag is exactly `v1.1.0`.
- Do not rebuild unless artifact integrity or version checks fail.
- Upload the installer, blockmap, and `latest.yml`.
- Do not publish until README and release text have been reviewed.
