# Ark Manager 1.1.0 Release Design

## Scope

- Refresh the README introduction and feature list so they describe the current application.
- Add an exhaustive Korean 1.1.0 changelog derived from `v1.0.1..master`.
- Reuse the approved changelog as the GitHub Release body.
- Publish the installer, blockmap, and `latest.yml` required by `electron-updater`.

## Release Identity

- Version: `1.1.0`
- Git tag: `v1.1.0`
- Release title: `Ark Manager 1.1.0`
- Repository: `kth5352/ArkManager`

## Content Rules

- Include user-facing features, behavior changes, compatibility migrations, and meaningful fixes added after `v1.0.1`.
- Do not describe the configurable external metadata provider as an unofficial mirror.
- State the RJ/VJ lookup order exactly: DLsite HTML, DLsite JSON, configured external API.
- State that WAV covers are app-local because WAV does not support the embedded cover stream used by the other formats.
- Keep the GitHub body readable as plain text because the in-app updater displays the body without Markdown rendering.

## Verification

- Check the README for duplicated lines and stale code names.
- Verify package versions and release artifacts are `1.1.0`.
- Verify installer SHA-512 against `latest.yml`.
- Confirm the remote tag, release body, and all updater assets after publication.
