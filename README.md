# Ark Manager

DLsite, Steam, VNDB, Getchu 게임과 로컬 미디어 라이브러리를 한 곳에서 관리하는 Windows용 데스크톱 앱입니다. PC에 흩어져 있는 온갖 동인 소프트웨어를 쉽게 관리하고 실행할 수 있도록 만들었습니다.

폴더를 라이브러리로 등록하면 `RJ`/`VJ`(DLsite), `ST`(Steam), `VNV`/`VNR`(VNDB), `GC`(Getchu) 식별 코드를 자동으로 인식하고, 표지·제목·제작사·발매일·태그 같은 메타데이터를 조회해 보여줍니다. 같은 식별 코드를 가진 파일은 메모, 평점, 세이브 백업 등 관리 데이터를 서로 공유합니다.

### 미디어 재생 기능

음성 파일(mp3, flac, wav, m4a)이나 영상 파일(mp4, mkv)을 재생할 수 있습니다. 뷰어와는 별개의 창으로 열리며, 음성 파일에 `.lrc` 같은 자막 파일이 있으면 자막을 함께 띄워줍니다. 재생목록 기반 랜덤 재생, 한 곡 반복재생, 팝업 창으로 열기 등 다양한 기능을 지원합니다. 동인 음성 감상용으로도, 버튜버 콘서트 영상 감상용으로도 사용하고 있습니다.

### 파일 탐색기 (Explorer)

간단한 파일탐색 기능을 제공합니다. 리스트/타일 보기가 가능하고, 드래그 앤 드롭으로 폴더째 파일 이동도 됩니다. 사이드바가 안 보이면 검색 버튼 오른쪽 아이콘을 눌러 다시 켤 수 있습니다.

### 플레이타임 기록

Ark Manager로 실행한 게임은 종료 시점에 플레이타임이 기록됩니다. 스팀처럼 "이 게임 깨는 데 몇 시간 걸렸는지" 확인할 수 있습니다. 단, 게임이 켜진 채로 Ark Manager를 먼저 종료하면 게임도 함께 꺼지면서 기록되지 않으니 주의하세요.

### 썸네일 변경

원하는 이미지로 손쉽게 표지(썸네일)를 바꿀 수 있습니다. 썸네일이 없으면 같은 폴더의 첫 번째 이미지를 자동으로 보여줍니다. WAV 파일은 자체적으로는 표지를 저장할 수 없지만, 대신 프로그램 내부에서 표지를 지정할 수 있습니다.

## 업데이트 내역

### 1.2.0 (2026.09.10)

미디어 재생·재생목록 기능을 대폭 확장하고, 앱 전반의 디자인과 애니메이션을 개선했습니다. 대규모 라이브러리의 처리 효율과 데이터 보호·오류 대응도 강화했습니다.

**미디어 플레이어**

- 재생 엔진을 libmpv 기반 네이티브 플레이어로 교체했습니다. 로컬 파일을 직접 재생하며, 기존 브라우저 기반 재생 및 임시 변환 경로를 제거했습니다.
- 재생 엔진을 별도 프로세스로 분리해 플레이어 오류가 앱 전체에 미치는 영향을 줄였습니다.
- 5밴드 이퀄라이저를 추가했습니다. 밴드별 음량 조절과 기본·저음·보컬·고음 강조 프리셋을 지원합니다.
- 음량과 이퀄라이저 설정을 저장하고 다음 실행 시 복원합니다.
- 하단 플레이어를 곡 정보와 재생 조작부로 나눈 2단 구성으로 개편했습니다.
- 하단 플레이어에서 전체화면 전환, 별도 창으로 분리, 좋아요와 재생목록 접근을 개선했습니다.
- 전체화면·분리 창에서도 일관된 조작부를 제공하고, 좁은 창에서 버튼이 넘치는 문제를 수정했습니다.

**재생목록과 미디어 탐색**

- 저장형 재생목록을 추가했습니다. 생성·이름 변경·삭제와 트랙 추가·제거·순서 변경을 지원합니다.
- 트랙 좋아요와 좋아요한 곡 모아보기를 추가했습니다.
- 현재 재생 대기열의 썸네일 표시와 드래그 순서 변경을 지원합니다.
- 재생목록 상세 화면과 사용자 지정 표지를 추가했습니다. 별도 표지가 없으면 트랙 이미지를 조합해 표시합니다.
- 미디어 사이드바에서 재생목록·현재 대기열·가사·폴더 트리를 확인할 수 있습니다.
- 미디어 탐색에 폴더별 보기, 경로 표시, 뒤로·앞으로 이동을 추가했습니다.
- 목록·그리드 보기 전환과 그리드 크기 조절을 추가했습니다.
- 단일 미디어 파일을 재생할 때 기존 대기열을 지우지 않고 추가하도록 변경했습니다.
- '다음에 재생'과 '저장된 재생목록에 추가' 기능의 접근성을 개선했습니다.
- 미디어 폴더를 변경한 뒤에도 저장된 재생목록과 좋아요한 곡의 재생·썸네일·가사를 사용할 수 있도록 수정했습니다.

**ASMR·가사·자막**

- DLsite 작품 유형을 인식해 ASMR·음성·음악·동영상 폴더를 실행 대신 재생으로 연결합니다.
- 해당 작품에서는 불필요한 실행 설정·세이브 관련 UI를 숨기고, 라이브러리와 탐색기에서 미디어 재생으로 진입할 수 있도록 개선했습니다.
- 기존 LRC에 더해 VTT·ASS 자막 파일을 지원합니다.
- 현재 구절을 자동으로 따라가는 가사 로그와 구절 클릭으로 해당 위치로 이동하는 기능을 추가했습니다.
- 자막만 별도 창에 띄우는 자막 PIP 기능을 추가했습니다.
- 자막 배경을 적용해 가독성을 높이고, ASS 도형 명령이 자막 로그에 문자로 노출되는 문제를 수정했습니다.
- 가사 로그를 직접 스크롤할 때 자동 따라가기가 방해하는 문제를 개선했습니다.

**라이브러리와 메타데이터**

- 코드가 연결된 작품도 표지를 직접 변경할 수 있습니다.
- 상세 사이드바·목록·상세 목록에 서클/제작사를 표시합니다. 이름을 클릭하면 해당 이름으로 검색합니다.
- 파일 메뉴에 전체 메타데이터 새로고침을 추가했습니다. 이미 수집된 작품 정보를 다시 가져오며, 실행 전 확인과 진행 상황 표시를 제공합니다.
- 코드가 없는 즐겨찾기 항목에서 라이브러리로 이동할 때 경로가 잘못 처리되는 문제를 수정했습니다.

**디자인과 애니메이션**

- 앱 기본 글꼴을 Pretendard로 변경하고, 글자 크기·색상·모서리·포커스·호버 스타일을 정리했습니다.
- 다크 모드에 맞춘 스크롤바를 적용했습니다.
- 사이드바와 도구 모음, 라이브러리 카드·목록, 탐색기와 보조 페이지의 시각적 구성을 개선했습니다.
- 페이지 전환, 메뉴·탭 선택, 버튼 누름, 썸네일 호버, 즐겨찾기·좋아요 변경에 애니메이션 피드백을 추가·정비했습니다.
- 상세 패널의 실행 설정·코드 연결·세이브 영역을 접고 펼칠 수 있도록 개선했습니다.
- 설정 화면을 주제별 카드로 재구성하고, 라이브러리 추가·제거 애니메이션을 적용했습니다.
- 툴팁의 표시 지연·위치·키보드 동작을 통일하고, 화면 가장자리에서 잘리는 문제를 개선했습니다.
- 긴 곡·재생목록 이름에 마우스를 올리면 전체 이름을 확인할 수 있도록 스크롤 표시를 추가했습니다.
- 긴 경로·탭 이름의 넘침, 전체화면 사이드바와 재생바의 겹침을 수정했습니다.
- 운영체제의 모션 감소 설정을 반영하도록 개선했습니다.

**성능 개선**

- 라이브러리의 필터·정렬·중복 분류 결과를 재사용해 불필요한 계산과 화면 갱신을 줄였습니다.
- 표지 이미지 캐싱을 개선해 스크롤 중 같은 이미지를 반복 요청하는 일을 줄였습니다.
- 미디어 썸네일의 지연 로딩·축소·캐싱을 개선했습니다.
- 동일 파일의 썸네일 요청을 합치고, 동시 추출 작업 수를 제한했습니다.
- 표지가 없는 파일도 결과를 캐싱해 불필요한 재탐색을 줄였습니다.
- 폴더 스캔의 동시 파일 조회 수를 제한하고, 응답이 없는 조회에 시간 제한을 적용했습니다.
- 창 사이에서 실제로 변경된 재생 상태만 동기화하도록 개선했습니다.
- 가사 전체가 재생 시간 갱신마다 다시 렌더링되는 문제를 개선했습니다.
- 오디오 재생과 일시정지 상태의 불필요한 영상 렌더링을 줄였습니다.

**오류 수정과 안정성**

- 다음 곡 자동 재생·한 곡 반복·재생 종료 감지를 수정하고, 곡 전환 시 재생 버튼이 깜빡이는 문제를 개선했습니다.
- 대기열을 비우거나 마지막 곡을 제거해도 소리가 계속 재생되는 문제를 수정했습니다.
- 일시정지 중 탐색·크기 변경 후 영상이 갱신되지 않는 문제를 수정했습니다.
- 분리된 플레이어 창의 초기 상태 동기화와 최소화·크기 변경 시 영상 처리를 개선했습니다.
- 재생목록 연속 편집 시 변경 내용이 덮어써지거나 중복 생성되는 문제를 수정했습니다.
- 별점·메모 로딩 전 편집으로 기존 값이 덮어써질 수 있는 문제를 방지했습니다.
- 세이브 비교에서 조회 실패와 빈 폴더를 구분하도록 개선했습니다.
- 세이브 복원 실패 시 원본 복구와 임시 파일 정리를 강화했습니다.
- 다른 드라이브로 파일을 이동하다 실패했을 때 불완전한 복사본이 남는 문제를 개선했습니다.
- 재생목록·라이브러리 삭제 전 확인 절차를 보강했습니다.
- 즐겨찾기·클리어·좋아요·세이브 관련 작업이 실패했을 때 오류 안내를 추가했습니다.
- 라이브러리 드라이브가 연결되지 않았거나 일부 저장 데이터가 손상된 상황의 오류 대응을 개선했습니다.
- 창을 닫은 뒤 메타데이터 일괄 수집이 멈춰 다시 시작되지 않는 문제를 수정했습니다.
- 실행·미디어 재생·탐색기 열기·세이브 경로 지정의 경로 검증을 강화했습니다.
- 앱 시작 오류 안내와 종료 시 재생 프로세스 정리를 개선했습니다.
- 앱에서 제공하는 사용자 지정 메뉴와 관련 확인창에 언어 설정이 반영되도록 수정했습니다.

## 시작하기

### 요구 사항

- Node.js (버전은 `.nvmrc` 참고)
- Windows (better-sqlite3 네이티브 모듈 빌드를 위한 빌드 도구 필요)

### 개발 모드

```bash
npm install
npm run dev
```

### 프로덕션 빌드 (설치 파일 생성)

```bash
npm run build
```

`electron-vite build`로 렌더러/메인 프로세스를 빌드한 뒤 `electron-builder`로 Windows NSIS 설치 파일을 만듭니다. 결과물은 `dist/`에 생성됩니다 (`dist/win-unpacked/`에 압축 안 된 실행 파일, `dist/Ark Manager Setup {version}.exe`에 설치 파일).

## 프로젝트 구조

```
electron/
  main/       # 메인 프로세스 - IPC 핸들러, DB, 스캐너, DLsite/Steam 크롤러, 파일 작업, 미디어 프로토콜
  preload/    # 렌더러에 노출하는 안전한 API 브리지 (contextBridge)
src/
  pages/      # 화면 단위 - Gallery, List, DetailList, Explorer, DLsite 검색, 즐겨찾기, 최근 플레이, 미디어, 세이브, 설정
  components/ # 공용 UI 컴포넌트 (game/, media/, layout/, ui/)
  hooks/      # 커스텀 훅
  services/   # React Query 기반 IPC 래퍼
  stores/     # Zustand 스토어
  i18n/       # 다국어 번역
shared/       # 메인·렌더러 공용 타입 및 IPC 스키마 (Zod)
```

## 데이터베이스

앱 자체 SQLite(`better-sqlite3`)를 사용하며, 스키마는 `electron/main/database/client.ts`에서 `CREATE TABLE IF NOT EXISTS` + 컬럼 백필 방식으로 직접 관리합니다. `npm run db:generate`/`npm run db:migrate`는 `drizzle-kit` 스키마 정의 참고용으로만 존재하며, 런타임 마이그레이션 파이프라인으로는 쓰이지 않습니다.

## 신뢰 경계

렌더러가 접근할 수 있는 모든 파일 시스템 작업(미디어 재생, 썸네일, 이름변경/이동/삭제, 실행 파일 지정 등)은 등록된 라이브러리 경로 아래로만 허용되도록 메인 프로세스에서 검증합니다.
