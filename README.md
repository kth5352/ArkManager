# Ark Manager

DLsite, Steam, VNDB, Getchu 게임과 로컬 미디어 라이브러리를 한 곳에서 관리하는 Windows용 데스크톱 앱입니다. 폴더를 라이브러리로 등록하면 RJ/VJ/ST/GC/VNV/VNR 식별 코드를 인식하고 표지, 제목, 제작사, 발매일과 태그를 조회해 보여줍니다.

## 주요 기능

- **세 가지 라이브러리 보기** - 표지 그리드(Gallery), 한 줄 목록(List), 컬럼별 상세 표(DetailList)에서 검색, 태그 필터, 파일 종류 필터, 중복 검사, 라이브러리 필터와 정렬 제공
- **통합 게임 검색** - DLsite, Steam, VNDB, Getchu 또는 전체 소스를 대상으로 코드와 제목 검색 및 메타데이터 조회
- **상세 정보와 실행 관리** - 평점과 메모 자동 저장, 즐겨찾기, 코드 연동, 커스텀 표지, 실행 파일과 Locale Emulator 설정, 플레이타임 및 최근 실행 기록
- **Explorer** - 탭, 목록/그리드 보기, 폴더 트리, 재귀 검색, 다중 선택, 일괄 이름 변경·이동·삭제, 드래그 앤 드롭 이동과 Ctrl+Z 실행 취소
- **내장 미디어 플레이어** - 재생목록, 반복과 셔플, 별도 플레이어 창, 전체 화면, 자동·수동 썸네일, LRC 동기화 가사와 재생을 유지하는 파일 새로고침
- **오디오 커버 관리** - MP3/FLAC/M4A에 검증 가능한 안전 절차로 표지 삽입, WAV를 포함한 미지원 형식에는 Ark Manager 전용 커버 적용
- **세이브 데이터 관리** - 스냅샷 생성·복원 전 변경점 미리보기, 메모와 버전 라벨, 버전 불일치 경고, 개별 또는 전체 삭제
- **목록 정리** - 경로별 항목 제외와 복원, 같은 코드의 즐겨찾기 통합, 종류별 중복 표시와 압축 해제 상태 표시
- **시스템 통합** - 창 닫기 동작을 묻기·종료·트레이 중에서 설정, 자동 업데이트 및 업데이트 내역 표시, 한국어·일본어·영어, 다크·라이트 모드

## 1.1.1 업데이트 내역

- 창을 닫을 때 `종료`, `트레이로 보내기`, `취소` 중에서 선택할 수 있는 확인 창을 표시합니다. 기본 버튼은 `종료`입니다.
- 선택 기억 체크박스를 사용하면 `종료` 또는 `트레이로 보내기` 선택이 저장되고 이후 확인 창을 표시하지 않습니다.
- 설정에서 창 닫기 동작을 `묻기`, `종료`, `트레이` 중에서 선택할 수 있으며, 저장된 설정이 없으면 기본값은 `묻기`입니다.
- 창 닫기 확인 창과 관련 설정 UI를 한국어·일본어·영어로 현지화했습니다.

## 1.1.0 업데이트 내역

### 메타데이터 및 게임 검색

- 게임 검색을 DLsite, Steam, VNDB, Getchu, 전체 검색으로 통합했습니다.
- Steam 공개 검색 API를 이용한 제목 검색과 Steam 메타데이터 조회를 추가했습니다.
- VNDB 제목 검색, 작품 정보 조회, VNDB 페이지 열기를 추가했습니다.
- Getchu 제목 검색, 작품 정보 조회, Getchu 페이지 열기를 추가했습니다.
- Getchu의 EUC-JP 검색어 인코딩, 연령 확인 페이지, 표지 이미지 핫링크 문제를 처리했습니다.
- Steam 검색에서 실행할 수 없는 번들 결과를 제외하고 탭 사이 검색 캐시가 섞이는 문제를 수정했습니다.
- 검색 결과 관련도와 VNDB 태그의 스포일러 필터링을 개선했습니다.
- 검색 결과가 있는 원래 검색 탭으로 돌아갈 수 있도록 이동 동작을 개선했습니다.
- 메타데이터 새로고침 후 Gallery, List, DetailList와 상세 정보가 즉시 갱신됩니다.
- RJ/VJ 수동 새로고침은 DLsite 작품 페이지, DLsite JSON 데이터, 사용자가 설정한 외부 API 순서로 조회합니다.
- 외부 메타데이터 API의 주소, 활성화 여부, Bearer API 키를 설정에서 구성할 수 있습니다.
- 조회에 실패한 공급자와 실패 원인을 기록하며 자동 재시도는 수행하지 않습니다.
- 메타데이터 일괄 조회 진행 문구를 특정 사이트에 종속되지 않도록 변경했습니다.

### VNDB 식별 코드

- VNDB 비주얼 노벨과 릴리스를 서로 다른 코드로 분리했습니다.
- `VNV123`은 VNDB의 `v123` 작품을, `VNR123`은 `r123` 릴리스를 나타냅니다.
- VNDB 릴리스 API에서 제목, 발매일, 제작사와 연결 작품 표지를 조회합니다.
- 버전 번호가 들어간 일반 파일을 `VN1` 등의 VNDB 코드로 잘못 인식하던 문제를 수정했습니다.
- 기존 VN/VR 데이터베이스 키를 VNV/VNR 형식으로 자동 이전합니다.
- 기존 VN/VR 코드로 생성된 세이브 스냅샷 디렉터리도 보존하여 이전합니다.
- 참조되지 않는 구형 VNDB 캐시는 정리하되 충돌 데이터와 사용자 정보는 보존합니다.

### Explorer

- 모든 파일과 폴더에 종류에 맞는 아이콘을 표시하고 일반 폴더 아이콘을 정돈했습니다.
- 다중 선택과 일괄 이름 변경, 이동, 삭제를 추가했습니다.
- 일괄 이름 변경이 끝난 뒤 선택 모드가 정상적으로 해제됩니다.
- 파일과 폴더를 다른 폴더, 탭 또는 폴더 트리로 끌어 이동할 수 있습니다.
- 이동 결과를 토스트로 표시하고 `Ctrl+Z`로 마지막 이동을 취소할 수 있습니다.
- 라이브러리 밖으로 이동하거나 검색 결과에서 잘못된 위치로 드롭하는 동작을 차단합니다.
- Explorer에 목록/그리드 보기를 추가하고 탭마다 보기 방식을 저장합니다.
- 그리드 크기 조절, 선택 모드 레이아웃, 검색 중 줌 컨트롤 상태를 수정했습니다.
- 크기 조절과 열림 상태가 저장되는 폴더 트리 사이드바를 추가했습니다.
- 폴더 트리는 활성 탭의 드라이브 또는 UNC 루트를 기준으로 표시합니다.
- 드라이브 루트와 UNC 경로의 부모·브레드크럼 처리 및 경로 비교를 보강했습니다.
- 사이드바 시작 시 깜빡임과 활성 경로 변경 시 불필요한 렌더링을 줄였습니다.
- 키보드 포커스 상태에서도 그리드 항목을 이동할 수 있습니다.
- 행, 폴더 이동, 탭 전환, 탭 추가·제거 버튼과 검색 전환 애니메이션을 정돈했습니다.
- `Ctrl+W`가 앱 전체가 아니라 현재 Explorer 탭만 닫도록 수정했습니다.
- 식별 코드가 있는 폴더를 클릭하면 상세 팝업 대신 해당 폴더로 이동합니다.
- Explorer 파일 작업 후 현재 목록이 즉시 새로고침됩니다.
- 압축 파일에 `.egg` 지원을 추가했습니다.
- 일반 파일에서는 평점, 메모, 코드 연동 등 지원되지 않는 동작을 숨깁니다.
- 실행 버튼은 실행 파일과 미디어 파일에만 표시되며, EXE는 직접 실행하고 미디어는 내장 플레이어에서 재생합니다.

### 미디어

- 비디오 프레임과 오디오 내장 앨범 아트를 자동으로 추출해 미디어 썸네일로 사용합니다.
- 자동 추출 썸네일 캐시와 사용자가 직접 지정하는 썸네일 덮어쓰기를 추가했습니다.
- 캐시 삭제 시 자동 추출된 미디어 썸네일도 함께 삭제됩니다.
- 오디오도 큰 화면과 별도 플레이어 창에서 재생할 수 있습니다.
- 셔플 재생과 재생목록 변경 시 셔플 순서 복구를 추가했습니다.
- 새 미디어를 열 때 음량이 최대로 초기화되던 문제를 수정했습니다.
- 파일 목록 새로고침은 현재 재생 중인 음악이나 영상을 중단하지 않습니다.
- 앱 전체 Reload가 재생을 중단하는 경우 확인 창을 표시합니다.
- 같은 이름 또는 인접한 `.lrc` 파일을 찾아 동기화 가사를 표시합니다.
- 가사는 켜기/끄기가 가능하며 일반 플레이어와 별도 플레이어 창에서 동작합니다.
- MP3, FLAC, M4A 표지 변경 시 원본 백업, 파일 변경, 재생 검증, 해시 검증 후 백업 삭제 순서로 처리합니다.
- 표지 삽입 실패 시 원본을 복원하고 Ark Manager 전용 커버로 전환합니다.
- 복구 검증에 실패하면 백업을 보존하고 해당 경로를 사용자에게 알립니다.
- WAV는 파일 형식 제약으로 표지를 파일에 삽입하지 않고 Ark Manager 전용 커버를 사용합니다.
- 크롤링 표지, 로컬 폴더 이미지와 사용자 지정 표지의 우선순위 및 폴백을 정리했습니다.

### 세이브 관리

- 세이브 스냅샷에 메모와 게임 버전 정보를 기록할 수 있습니다.
- 개별 스냅샷 삭제, 전체 삭제, 탐색기에서 위치 열기를 추가했습니다.
- 현재 실제 세이브 폴더를 바로 열 수 있습니다.
- 실행 파일의 PE 버전과 파일명 패턴을 이용해 게임 버전을 자동 감지합니다.
- 스냅샷과 현재 게임의 버전이 다르면 복원 전에 호환성 경고를 표시합니다.
- 세이브 페이지에 게임 검색을 추가했습니다.
- 스냅샷이 하나도 없는 게임은 세이브 목록에서 숨깁니다.
- 실행 파일 버전 조회 과정의 명령어 삽입 가능성을 제거했습니다.

### 라이브러리 및 즐겨찾기

- Gallery, List, DetailList에서 개별 경로를 목록에서 제외할 수 있습니다.
- 보기 메뉴의 제외 항목 관리 창에서 숨긴 경로를 확인하고 복원할 수 있습니다.
- 같은 코드가 여러 경로에 있어도 제외 설정은 선택한 경로에만 적용됩니다.
- 즐겨찾기에는 같은 코드의 게임을 하나의 대표 항목으로만 표시합니다.
- 즐겨찾기 게임을 클릭하면 Gallery로 이동해 해당 식별 코드를 검색합니다.
- 중복 표시는 폴더, 압축 파일, 일반 파일처럼 같은 종류끼리만 계산합니다.
- 같은 코드의 폴더가 존재하는 압축 파일에는 압축 해제됨 상태를 표시합니다.

### UI 및 시스템

- 앱 전체의 버튼, 입력 필드, 토스트 알림과 상태 피드백 스타일을 통일했습니다.
- 업데이트 내역에 GitHub HTML 태그가 그대로 표시되던 문제를 수정했습니다.
- 검색 버튼을 열면 일반 검색과 태그 검색 필드가 함께 확장되고 축소됩니다.
- 상세 사이드바의 실행, 삭제, 새로고침 버튼 배치와 툴팁을 정돈했습니다.
- 실행 설정 저장 후 창을 닫고 결과를 토스트로 알리며 필요하면 즉시 실행합니다.
- 게임을 전환했을 때 이전 게임의 이름 변경, 이동, 삭제, 실행 설정 창 상태가 남는 문제를 수정했습니다.
- 여러 확인 창에서 중복 React 키 경고가 발생하던 문제를 수정했습니다.
- 창 닫기 시 앱을 종료하지 않고 시스템 트레이에서 계속 실행할 수 있습니다.
- 트레이 메뉴와 더블 클릭으로 창을 다시 열고, 종료 메뉴로 앱을 완전히 종료할 수 있습니다.
- `Ctrl+Plus`, `Ctrl+Shift+=`, 숫자 키패드 `+`를 포함한 확대 단축키를 메인 창과 별도 플레이어 창에서 지원합니다.

## 기술 스택

- [Electron](https://www.electronjs.org/) + [electron-vite](https://electron-vite.org/)
- React 19 + TypeScript (strict)
- Tailwind CSS v4 + shadcn/ui
- Zustand · TanStack Query · TanStack Router
- Drizzle ORM + better-sqlite3
- react-window (가상 스크롤) · Vitest

## 시작하기

### 요구 사항

- Node.js (버전은 `.nvmrc` 참고)
- Windows (better-sqlite3 네이티브 모듈 빌드를 위한 빌드 도구 필요)

### 개발 모드

```bash
npm install
npm run dev
```

### 프로덕션 빌드 (설치 파일 생성)

```bash
npm run build
```

`electron-vite build`로 렌더러/메인 프로세스를 빌드한 뒤 `electron-builder`로 Windows NSIS 설치 파일을 만듭니다. 결과물은 `dist/`에 생성됩니다 (`dist/win-unpacked/`에 압축 안 된 실행 파일, `dist/Ark Manager Setup {version}.exe`에 설치 파일).

## 스크립트

| 명령                   | 설명                          |
| ---------------------- | ----------------------------- |
| `npm run dev`          | 개발 모드 실행 (HMR)          |
| `npm run build`        | 프로덕션 빌드 + 패키징        |
| `npm run lint`         | ESLint                        |
| `npm run typecheck`    | TypeScript 프로젝트 참조 빌드 |
| `npm run test`         | Vitest                        |

## 프로젝트 구조

```
electron/
  main/       # 메인 프로세스 - IPC 핸들러, DB, 스캐너, DLsite/Steam 크롤러, 파일 작업, 미디어 프로토콜
  preload/    # 렌더러에 노출하는 안전한 API 브리지 (contextBridge)
src/
  pages/      # 화면 단위 - Gallery, List, DetailList, Explorer, DLsite 검색, 즐겨찾기, 최근 플레이, 미디어, 세이브, 설정
  components/ # 공용 UI 컴포넌트 (game/, media/, layout/, ui/)
  hooks/      # 커스텀 훅
  services/   # React Query 기반 IPC 래퍼
  stores/     # Zustand 스토어
  i18n/       # 다국어 번역
shared/       # 메인·렌더러 공용 타입 및 IPC 스키마 (Zod)
```

## 데이터베이스

앱 자체 SQLite(`better-sqlite3`)를 사용하며, 스키마는 `electron/main/database/client.ts`에서 `CREATE TABLE IF NOT EXISTS` + 컬럼 백필 방식으로 직접 관리합니다. `npm run db:generate`/`npm run db:migrate`는 `drizzle-kit` 스키마 정의 참고용으로만 존재하며, 런타임 마이그레이션 파이프라인으로는 쓰이지 않습니다.

## 신뢰 경계

렌더러가 접근할 수 있는 모든 파일 시스템 작업(미디어 재생, 썸네일, 이름변경/이동/삭제, 실행 파일 지정 등)은 등록된 라이브러리 경로 아래로만 허용되도록 메인 프로세스에서 검증합니다.
